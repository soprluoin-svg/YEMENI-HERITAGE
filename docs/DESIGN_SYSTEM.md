# Design system

| Token            | Value   | Role                         |
| ---------------- | ------- | ---------------------------- |
| Aged Copper      | #96532F | Warm material accent         |
| Burnished Bronze | #B87345 | Illuminated metal            |
| Roasted Coffee   | #3B241B | Dark surface                 |
| Deep Espresso    | #241813 | Atmospheric base             |
| Copper Shadow    | #593627 | Dark gradient                |
| Dark Walnut      | #513B30 | Mid shadow                   |
| Sandstone        | #C6B49E | Architectural surface        |
| Warm Ivory       | #E8DED0 | Light foreground and surface |
| Sage Olive       | #858D78 | Natural stone accent         |
| Muted Teal       | #66827C | Natural secondary accent     |
| Dusty Rose       | #B58D87 | Warm secondary accent        |
| Soft Taupe       | #A79683 | Stone shadow                 |

Opening uses espresso and copper illumination. Ibex uses a walnut gallery surface. Bab Al-Yemen uses warm ivory and sandstone. Dar Al-Hajar uses muted olive and warm stone. Coffee returns to roasted darkness. Use light ink on dark surfaces, espresso ink on light surfaces and verify contrast against the composited background. Use logical CSS properties and retain the same scene IDs in both languages.

Use Cormorant Garamond for English display, DM Sans for English interface and body, and IBM Plex Sans Arabic for Arabic. Use bounded fluid type, editorial grids that stack at narrow widths and restrained copper rules.
