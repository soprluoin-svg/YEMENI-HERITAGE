# Project scope

Phase 01 covers the public exhibition at the English root route and Arabic /ar, five in-page scenes, responsive UI, scene themes, approved visual tokens, honest development placeholders, static rendering, restrained animation and permanent project governance. The portfolio contact action routes to the project owner's public GitHub profile until a dedicated destination is supplied.

Later phases cover final 3D models, physically rendered materials and lighting, the full camera and scroll choreography, and final publication. There is no commerce, booking, CMS or backend in Phase 01.
