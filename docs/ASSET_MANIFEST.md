## Owner-supplied concept references

The owner supplied five concept images. Capture their role here so future sessions can apply the references without relying on conversation memory.

- **Copper ibex.** Use the large ridged curling horn, elevated head, elongated muzzle, beard, compact body and bent raised front leg as proportion and material reference. The web cutout is a processed 2D derivative of this reference. Retain the original reference for production modeling.
- **Two coffee beans.** Keep the dragon’s blood tree relief bean and the rock-palace relief bean separate. The reference presents them on a shared display plinth, while the exhibition’s planned objects have independent transforms and motion. Use the tree image for canopy and branch structure. It supports the coffee scene as a motif.
- **Dar Al-Hajar.** Use the concept for light, masonry and color direction. Verify tiering, window placement, gypsum and the rock foundation against documentary sources before building production geometry.
- **Bab Al-Yemen.** Use the studio diorama for material and framing direction. Verify towers, gateway width, windows and ornament against documentary sources before building production geometry.

The working copy contains the optimized ibex derivative and the generated highlands plate. Archive the original reference files and confirm source/rights with the owner before publishing the final assets.
