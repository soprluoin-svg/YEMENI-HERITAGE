# Testing strategy

Run npm lint through `npm run lint`, strict TypeScript through `npm run typecheck` and the production build through `npm run build`. Open the built application and check both languages, section anchors, mobile disclosure, keyboard focus and Escape, reduced-motion behavior, browser console, and horizontal overflow at representative widths.

Targets for a deployed field profile at the 75th percentile are LCP at most 2.5 s, CLS at most 0.1 and INP at most 200 ms. Phase 01 transfer budgets are 500 KiB compressed for the hero plate at its largest responsive size and 230 KiB compressed for initial JavaScript (framework and route). Measure using the production network waterfall, and keep WebGL dependencies off the route entirely. Future 3D assets get separate budgets before integration.
